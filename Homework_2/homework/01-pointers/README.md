# Задание 1. Указатели: увеличьте число

На работу — примерно 5–10 минут. Используйте стандартную библиотеку.
Пишите решение в [main.go](main.go): функции объявляйте на уровне пакета,
а примеры вызовов — внутри `main`. Для вывода подключите `fmt`.

Реализуйте функцию из заготовки:

```go
func Increment(value *int)
```

Она должна увеличить число по переданному указателю на `1`.
Если передан `nil`, функция должна завершиться без изменений и без `panic`.

**Проверьте в `main`:**

```go
number := 10
Increment(&number)
fmt.Println(number) // 11

Increment(&number)
fmt.Println(number) // 12

Increment(nil) // программа продолжает работать
```

**Готово, если:** изменяется переменная в `main`, а вызов с `nil` не приводит
к панике.

**Объясните:** что означают `&number` и `*value`? Почему для изменения
исходного числа здесь нужен указатель?
