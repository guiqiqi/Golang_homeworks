# Домашние задания к уроку 3

Три коротких задания для закрепления указателей, срезов и `map`.
На каждое — примерно 5–10 минут. Используйте стандартную библиотеку.

| Задание | Что закрепляем |
|---|---|
| [1. Увеличьте число](01-pointers/README.md) | Указатели, `&`, разыменование и `nil` |
| [2. Сумма и добавление в срез](02-slices/README.md) | Обход среза, `append` и общий базовый массив |
| [3. Баллы студентов](03-maps/README.md) | Создание, изменение, поиск и удаление в `map` |

У каждого задания своя папка с условием в `README.md`, заготовкой `main.go`
и автотестами в `main_test.go`.
Решайте и запускайте задания по отдельности. Команды запуска и ожидаемые
результаты приведены в условиях.

Для запуска всех автотестов из корня каталога урока:

```bash
cd homework
go test ./...
```

Нужен Go 1.22 или новее. Модуль уже создан, дополнительные зависимости не нужны.
Пока функции в заготовках не реализованы, тесты должны падать. Допишите функции,
сохраняя их сигнатуры, и добейтесь прохождения тестов, не меняя проверки.
Автотесты проверяют функции; вывод в `main` и ответы на вопросы проверьте сами.
