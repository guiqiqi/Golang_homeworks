# Задание 2. Срезы: посчитайте сумму и добавьте элемент

На работу — примерно 5–10 минут. Используйте стандартную библиотеку.
Пишите решение в [main.go](main.go): функции объявляйте на уровне пакета,
а примеры вызовов — внутри `main`. Для вывода подключите `fmt`.

Реализуйте функцию из заготовки:

```go
func Sum(numbers []int) int
```

Она должна пройти по срезу циклом и вернуть сумму его элементов,
не меняя их. Для пустого среза и `nil` результат должен быть `0`.

**Проверьте в `main`:**

```go
numbers := []int{2, 4, 6, 8, 10}
fmt.Println(Sum(numbers)) // 30
fmt.Println(Sum([]int{})) // 0
fmt.Println(Sum(nil)) // 0
fmt.Println(Sum([]int{-2, -1, 0, 1, 2})) // 0
```

Добавьте число `12` через `append`, сохранив результат в `numbers`.
Выведите длину среза и новую сумму: ожидаются `6` и `42`.

Затем присвойте срез другой переменной и измените первый элемент:

```go
shared := numbers
shared[0] = 100
fmt.Println(numbers[0], shared[0]) // 100 100
```

**Готово, если:** суммы верны, пустой срез и `nil` обработаны, после добавления
длина равна `6`, а изменение через `shared` видно и через `numbers`.

**Объясните:** что копируется при присваивании среза и при передаче
его в `Sum`? Почему изменение через `shared` видно через `numbers`?
Зачем сохранять результат `append`?
