# Задание 3. Map: сохраните баллы студентов

На работу — примерно 5–10 минут. Используйте стандартную библиотеку.
Пишите решение в [main.go](main.go): функции объявляйте на уровне пакета,
а примеры вызовов — внутри `main`. Для вывода подключите `fmt`.

Реализуйте функцию из заготовки:

```go
func StudentScores() map[string]int
```

Внутри неё создайте через `make` переменную `scores` типа `map[string]int`.
Ключ — имя студента, значение — количество баллов.

Выполните действия по порядку:

1. Добавьте Анну с `3` баллами, Бориса с `0` и Веру с `5`.
2. Увеличьте баллы Анны на `2`.
3. Удалите Веру через `delete` и верните получившуюся `map` из функции.
4. В `main` вызовите `StudentScores` и выведите баллы Анны.
5. Найдите Бориса и Глеба через `score, ok := scores[name]`.
   Для каждого выведите и баллы, и признак наличия ключа.
6. Выведите длину `map`.

**Ожидаемые результаты:**

| Проверка | Результат |
|---|---|
| Баллы Анны после изменения | `5` |
| Поиск Бориса: `score`, `ok` | `0 true` |
| Поиск Глеба: `score`, `ok` | `0 false` |
| Длина после удаления Веры | `2` |

**Готово, если:** значения совпадают с таблицей, а `map` создана до первой
записи. Порядок вывода элементов всей `map` проверять не нужно.

**Объясните:** почему одних баллов `0` недостаточно, чтобы понять,
есть ли студент в `map`? Что произойдёт при записи, если вместо `make`
использовать только `var scores map[string]int`?
