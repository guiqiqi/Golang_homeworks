# Starter СР-1

Реализуйте `AnalyzeSales` в файле `analytics.go`. Не меняйте названия, типы полей
и сигнатуру функции: по ним запускаются автотесты.

```bash
go test ./...
gofmt -w .
```

Перед сдачей добавьте в этот README краткое описание алгоритма и его сложности.

---

Функция `AnalyzeSales` завершена: сначала инициализируется `Report` (компонент `map` требует дополнительного внимания к выделению памяти); затем цикл перебирает все записи о продажах. `map` используется для записи продаж по каждой категории, и, наконец, вычисляется самая продаваемая категория.

В тестирование добавлены три тестовых случая: один для пустого ввода, один для всех возможных ошибочных входных данных и один для проверки того, что функция не изменяет входные данные.

- Временная сложность: O(n + m), где `n` — количество записей о продажах, а `m` — количество различных товаров.

- Пространственная сложность: O(c + m), где `c` — количество различных категорий, в основном используется в двух операциях отображения.
